# Elehant.exe — прототип для Windows

**Готовый файл:** [Elehant.exe v0.1.0](https://github.com/Drujnv/elehant/releases/download/v0.1.0/Elehant.exe) (Windows x64, один файл, без Python).

## Что делает

- слушает BLE-рекламу счётчиков Элехант (`0xFFFF`);
- показывает таблицу: прибор, тип/канал, м³, °C, сырую батарею, «вода идёт / нет»,
  время последнего пакета, Δ к показанию табло, деньги;
- строит график объёма по выбранному прибору;
- пишет каждый пакет в `%USERPROFILE%\Elehant\readings.jsonl`;
- **деньги — по желанию**: поле «Тариф, ₽/м³» можно оставить пустым;
- **расход только при росте объёма**: если объём не меняется, а температура
  пришла — это не вода, расход = 0;
- Δ к табло считается по введённому показанию; это не «подкрутка» декодера.

## Как запустить

1. Включить Bluetooth на Windows 10/11.
2. Запустить `Elehant.exe` (SmartScreen может спросить — «Подробнее → Выполнить»).
3. Дождаться появления приборов (30–60 секунд; без расхода пакеты реже).
4. Выбрать прибор в таблице.
5. При желании: ввести тариф (₽/м³) и/или показание с табло → «Сохранить».
6. График обновляется по мере пакетов.

## Сборка из исходников

```powershell
py -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pyinstaller --noconfirm --onefile --windowed --name Elehant --paths . elehant_app.py
```

Или `build_exe.ps1`.

## Ограничения прототипа

- пока нет выбора BLE-адаптера;
- нет экспорта в Excel (JSONL/CSV — позже);
- график — объём; температура пока в таблице;
- эталон/тариф хранятся в `%USERPROFILE%\Elehant\settings.json`;
- это **не** замена официальному учёту: приложение для контроля.

## Проверка

SHA-256 текущей сборки указан в `SHA256.txt`.
