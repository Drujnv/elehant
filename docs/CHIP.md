# Чип, плата и физический доступ

## 1. Микроконтроллер

| Параметр | Значение |
|---|---|
| Чип | **nRF24LE1** (Nordic Semiconductor), QFN24 |
| Ядро | 8051 |
| Флеш | 16 КБ (F16) |
| Радио | 2,4 ГГц, proprietary nRF24 + BLE-реклама в прошивке прибора |
| Кварц | 16,000 МГц |
| Плата | маркировка `Elehant 2.83` |
| Антенна | меандровая, на плате |
| Питание | литиевая батарея в отсеке |

nRF24LE1 — это **не «голый» nRF24L01+**: у него есть собственный флеш, UART, SPI,
ADC, GPIO. Прошивка прибора реализует BLE-рекламу и логику счётчика.

## 2. Что выведено на плату

- батарейный отсек;
- `OUT` — импульсный выход датчика расхода;
- `NTC` — вход термодатчика;
- `A2` — служебная/аналоговая площадка;
- два ряда площадок **`G / RX / TX / G`** — UART;
- верхний 8-контактный гребень — заводские тестовые цепи.

## 3. UART

Подключение FT232BL (только для лога, **без питания платы от 5 В**):

| FT232BL | Плата |
|---|---|
| GND | G (любой) |
| TXD | RX |
| RXD | TX |
| 3V3/5V | **не подключать** |

Джампер FT232BL — **3V3**. Скорость: начать с **9600 8N1**, затем 19200, 38400,
57600, 115200. Слушать с момента включения/вставки батареи.

## 4. SPI-программирование (дамп флеша)

Флеш nRF24LE1 читается **не по UART**, а по SPI-интерфейсу программирования:

| nRF24LE1 | Пин QFN24 | Программатор |
|---|---:|---|
| PROG | 5 | DCD |
| RESET | 13 | DSR |
| FCSN (P0.5) | 11 | RXD |
| FMOSI (P0.3) | 9 | CTS |
| FMISO (P0.4) | 10 | RTS |
| FSCK (P0.2) | 8 | DTR |
| VDD | 3,3 В | VCCIO 3,3 В |
| GND | — | GND |

FT232BL **не подходит** для SPI: на его гребёнке нет RTS/CTS/DTR/DSR/DCD.
Нужны FT232R с полным набором, Arduino (скетч `nRF24LE1_Programmer`) или пайка
на выводы чипа.

**Перед записью:** прочитать и сохранить **InfoPage 512 байт** и полный флеш.
Иначе можно потерять калибровку/серийник. После перепрошивки прибор перестаёт
быть средством измерения — только снятая/донорская плата.

Инструменты:
- [polkabana/nRF24LE1_Programmer](https://github.com/polkabana/nRF24LE1_Programmer) — Arduino;
- [puskyer/nrf24le1_flasher](https://github.com/puskyer/nrf24le1_flasher) — FT232R;
- [derekstavis/nrf24le1-libbcm2835](https://github.com/derekstavis/nrf24le1-libbcm2835) — Raspberry Pi;
- [sonocotta/nRF24LE1-Example](https://github.com/sonocotta/nRF24LE1-Example) — примеры SDK.

## 5. Что можно сделать из платы (донорской)

- BLE-маяк с датчиком (температура/импульсы);
- счётчик импульсов воды/газа (`OUT` + свой код);
- автономный логгер температуры (NTC) и протечки;
- радиокнопка/датчик на nRF24;
- эмулятор счётчика для стенда (вне коммерческого учёта).

Ограничения: 16 КБ флеш, 8051, мало RAM, SDK Nordic (SDCC/Keil), нет Arduino-ядра
«из коробки».

## 6. Юридически и этически

- читаем **свои** приборы;
- не публикуем чужие серийники/адреса;
- не выкладываем прошивки и бинарники;
- не помогаем обходить учёт/поверку;
- перепрошивка учётного прибора аннулирует поверку — это ответственность владельца.

## 7. Что осталось выяснить

- распиновка тестового гребня (не только UART);
- доступ к InfoPage без пайки;
- есть ли сервисные команды в UART;
- где хранится дата поверки (B1/облако/флеш).
