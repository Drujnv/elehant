# Метрология: почему Элехант — измерительный прибор

> Это выжимка из документов, которые владелец присылал 12.10.2026. Это не
> юридическое заключение; перед спором с УК/РСО нужны заверенные документы.

## 1. Что за прибор

| Модель | Тип | Регистр |
|---|---|---|
| СВТ-15 (горячая вода) | счётчик воды с измерением температуры и объёма по порогу | **ГРСИ 72647-18** |
| СВД-15 / СВУ (холодная) | счётчик воды | **ГРСИ 61754-15** |

Изготовитель: **ООО «Элехант» / ООО «КИЮн»**, г. Омск (торговая марка «Элехант»).
Свидетельство об утверждении типа СВТ действует **до 27.09.2028**, производство
серийное, межповерочный интервал — **6 лет**, срок службы — 12 лет.

## 2. Что написано в описании типа (СВТ, 72647-18)

| Характеристика | Значение |
|---|---|
| Расход Qmin / Qt / Qn / Qmax | 0,03 / 0,12 / **1,50** / 3,00 м³/ч |
| Порог чувствительности | 0,015 м³/ч |
| Погрешность объёма (Qmin–Qt / Qt–Qmax) | **±5,0 % / ±2,0 %** |
| Метрологический класс по **ГОСТ Р 50193.1-92 (ИСО 4064/1-77)** | **B** |
| Цена деления выносного индикатора | 0,001 м³ |
| Ёмкость индикатора | 99 999,999 м³ |
| **Диапазон измерения температуры воды** | **0…+100 °C** |
| **Предел допускаемой абсолютной погрешности температуры** | **±1,0 °C** |
| **Порог деления объёма по температуре** | задаётся в диапазоне **+20…+60 °C**, значение — в паспорте (у наших — **+40 °C**) |
| Комплектность | счётчик, монтажные части, выносной индикатор, паспорт **ЭЛХТ.407279.002 ПС**, методика поверки |
| Методика поверки | **ОЦСМ 040196-2018 МП** |
| Знак поверки | паспорт + счётчик (первичная), свидетельство + счётчик (периодическая) |

### Ключевое

- температура — **измерительный канал** утверждённого типа, а не «дополнительная
  функция»;
- прибор делит объём по **одному** настраиваемому порогу (у нас +40 °C) на два
  регистра: **ниже** и **выше** порога;
- «гибкий учёт каждые 3 °C» — это **правило расчёта** по п. 5 приложения № 1
  Правил № 354, а не функция счётчика;
- порог выше **+60 °C** задать нельзя; отдельного регистра «выше 75 °C» нет.

## 4а. Как именно поверяли (Омский ЦСМ)

Первичная поверка 08.2026 — **ФБУ «Омский ЦСМ»**, аккредитация **RA.RU.311220**.  
Методика: **ОЦСМ 040196-2018 МП** «ГСИ. Счётчики воды СВТ. Методика поверки»,
утверждена ФБУ «Омский ЦСМ» (2018), распространяется на СВТ по **ЭЛХТ.407279.002 ТУ**.

Операции (таблица 1 методики): внешний осмотр, герметичность, опробование
(включая порог чувствительности), идентификационные данные, определение
относительной погрешности объёма, **абсолютной погрешности температуры**,
проверка ПО.

Критерий по температуре (п. 7.4.2.5): прибор пригоден, если **абсолютная
погрешность температуры ≤ ±1,0 °C**. То есть температурный канал — **поверяемая
величина**.

Эталоны (из описания типа 72647-18):
- рабочий эталон объёмного расхода/объёма 3-го разряда, 0,03–2,75 м³/ч,
  соотношение погрешностей ≥ 1:3;
- лабораторный электронный термометр **ЛТ-300** (рег. № 61806-15),
  погрешность **±0,05 °C** в диапазоне −50…+199,99 °C.

Нормативная база поверки:
- **102-ФЗ**, ст. 12–14;
- **Приказ Минпромторга № 2510** (порядок поверки, знак, свидетельство);
- **Приказ Минпромторга № 2906** (сведения в ФГИС «Аршин»);
- **Приказ Росстандарта № 256** (поверочная схема объёма/расхода);
- **ГОСТ Р 50193.1-92**, **ГОСТ Р 50601-93**.

**Честное ограничение:** публичный поиск в ФГИС «Аршин» по заводскому номеру
программно недоступен (403/браузерный токен); для параллельного импорта номер
может быть заменён инвентарным. Поэтому в публичном проекте — только методика и
модели, без серийников; официальную выписку владелец получает вручную.

## 5. Что это даёт для публичного проекта

1. Мы читаем **не «игрушку», а средство измерения** утверждённого типа.
2. Температура имеет нормированную погрешность **±1,0 °C** — можно обсуждать
   качество ГВС, а не «примерно».
3. Два регистра (ниже/выше +40 °C) — штатная функция, а не наша фантазия.
4. Наш BLE-сбор — **внутренний мониторинг**; для официальных расчётов нужна
   поверка, паспорт и, при споре, официальная выгрузка/свидетельство.
5. Публичный проект не должен обещать «заменим УК»; он даёт **прозрачные данные
   и доказательства**.
